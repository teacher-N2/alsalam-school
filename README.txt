نسخة التبويبات الاحترافية

الجديد:
- تبويبات جانبية واضحة مثل المواقع الاحترافية.
- بوابة استكشاف ببطاقات تشويقية.
- كل تبويب يفتح محتوى خاصًا بالقسم داخل نفس الصفحة.
- زر عرض التقرير كاملًا + نسخ + طباعة.
- صوت يعمل بعد الضغط على زر الصوت أو افتتاح الموقع.
- معرض صفحات كامل.
